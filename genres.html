A genre joins the first group (top to bottom) that has one of its words as a whole word. Separate keywords with commas, e.g. house, amapiano.

Rules live in genre_groups.json in the site's GitHub repository.

Save to GitHub

GitHub only lets the repository owner (and people they add) save. Takes about 30 seconds:

  1. Tap Copy rules.
  2. Tap Open GitHub editor and sign in if asked.
  3. In the editor, select all the text (long-press → Select all), then paste.
  4. Tap Commit changes… → Commit changes.

The site updates in about a minute; new suggestions follow automatically.
